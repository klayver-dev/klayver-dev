## 🚀 Sobre Mim

Sou desenvolvedor Full Stack com foco no desenvolvimento de aplicações web modernas, atuando tanto no backend quanto no frontend.

Tenho experiência no desenvolvimento de sistemas utilizando PHP, Laravel, JavaScript, TypeScript, React e Next.js, além de modelagem e gerenciamento de bancos de dados com MySQL e Prisma ORM.

Atualmente estou aprofundando meus conhecimentos em arquitetura de software, desenvolvimento backend, banco de dados, cloud e boas práticas de engenharia de software, buscando construir aplicações escaláveis, performáticas e de alta qualidade.
